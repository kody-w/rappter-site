NO PUBLIC INSTALLER

The first proof needs no installation.

RapterBox LLC does not publish a generic bootstrap command or redirect renters to unrelated installation material. The customer sees a synthetic proof before any local package or system access is discussed.

Current status

Public installation is intentionally unavailable. An accepted rental may receive a private, recipient-bound package only after the customer approves the proof and the operator verifies the rental, signature, scope, expiry, and cleanup contract.

Private delivery gate

  1. A bounded rental is manually accepted.
  2. The renter approves the synthetic proof.
  3. A recipient key and exact rental identity are bound.
  4. The package manifest and tether are signed.
  5. Delivery is time-bounded and revocable.
  6. Expiry removes the exact execution artifacts while preserving approved outputs and receipts.

Do not install from an unrelated route

Third-party, cloud, or generic installers are not a RapterBox LLC rental package. A valid delivery will identify RapterBox LLC, the exact rental, recipient binding, package hash, signature, and expiry.
